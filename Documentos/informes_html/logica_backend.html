Leyenda de Tipos

Etiqueta Significado
SELECT Solo lectura de datos
INSERT Creación de registros nuevos
UPDATE Modificación de registros existentes
DELETE Eliminación de registros
🔥 ATÓMICO Transacción que ejecuta múltiples operaciones (INSERT/UPDATE/DELETE) de forma indivisible
JSON ESTÁTICO Retorna JSON fijo (mock), preparado para migrar a tabla dinámica
SELECT+JOIN Lectura con JOIN a múltiples tablas (todo oculto al PHP)
SELECT+GROUP Lectura con agrupación para estadísticas/gráficas
INSERT/UPDATE Crea si no existe, actualiza si ya existe (UPSERT)
