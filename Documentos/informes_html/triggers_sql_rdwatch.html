⚙️ Función Base: fun_audit_rdwatch()

Función PL/pgSQL ejecutada automáticamente por cada trigger · RETURNS TRIGGER
¿Qué hace? Se ejecuta BEFORE INSERT OR UPDATE en cada tabla. Llena automáticamente las columnas de auditoría sin que el programador PHP tenga que hacerlo manualmente.
# Operación Tipo Propósito Columnas que Modifica
1 fun_audit_rdwatch() — en INSERT INSERT Cuando se inserta un registro nuevo, llena automáticamente las 4 columnas de creación y actualización con el usuario actual y la fecha/hora. usr_insert = CURRENT_USER
fec_insert = NOW()
usr_update = CURRENT_USER
fec_update = NOW()
2 fun_audit_rdwatch() — en UPDATE UPDATE Cuando se actualiza un registro existente, preserva los campos originales de inserción y solo actualiza los campos de modificación. usr_insert = OLD.usr_insert (preserva)
fec_insert = OLD.fec_insert (preserva)
usr_update = CURRENT_USER
fec_update = NOW()
📊 Flujo de ejecución:
1️⃣ PHP llama una función fn_* (blindaje) o fun_* (legacy)
2️⃣ La función ejecuta un INSERT o UPDATE en alguna tabla
3️⃣ El trigger tri_audit_* se dispara automáticamente (BEFORE)
4️⃣ fun_audit_rdwatch() llena las columnas usr_insert/fec_insert/usr_update/fec_update
5️⃣ El registro se guarda con la trazabilidad completa
