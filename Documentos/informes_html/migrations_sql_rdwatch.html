¿Qué es una migración? Es un cambio incremental al esquema de base de datos (ALTER TABLE, CREATE INDEX, etc.) que se aplica después de la creación inicial de las tablas. Se usa cuando se necesita agregar funcionalidad sin recrear toda la base de datos.

📸 add_foto_to_reservas.sql

20 líneas · Tabla: tab_Reservas · Agrega soporte para fotos adjuntas en citas de servicio
# Operación Tipo Propósito Tabla
1 ALTER TABLE tab_Reservas ADD COLUMN foto_adjunto BYTEA ALTER TABLE Agrega columna para almacenar la foto adjunta como datos binarios (BYTEA). Permite que el cliente suba una foto del reloj al crear una cita de reparación. tab_Reservas
2 ALTER TABLE tab_Reservas ADD COLUMN foto_extension VARCHAR(10) ALTER TABLE Agrega columna para guardar la extensión del archivo (jpg, png, svg). Se usa al servir la imagen para establecer el Content-Type correcto. tab_Reservas
3 CREATE INDEX idx_reservas_con_foto ON tab_Reservas (...) WHERE foto_adjunto IS NOT NULL INDEX PARCIAL Índice parcial que solo indexa reservas que tienen foto adjunta. Optimiza las consultas de búsqueda sin desperdiciar espacio en registros sin foto. tab_Reservas
4 COMMENT ON COLUMN tab_Reservas.foto_adjunto COMMENT Documentación inline en la base de datos: especifica formatos permitidos (JPG, PNG, SVG) y tamaño máximo recomendado. tab_Reservas
5 COMMENT ON COLUMN tab_Reservas.foto_extension COMMENT Documentación inline: indica que la extensión se usa para reconstruir el Content-Type HTTP al servir la imagen. tab_Reservas
