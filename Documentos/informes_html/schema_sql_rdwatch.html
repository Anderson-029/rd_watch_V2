Convenciones del Schema

Convención Descripción
Prefijo tab_ Todas las tablas usan este prefijo para distinguirlas de vistas y funciones.
Auditoría (6 columnas) Cada tabla tiene: usr_insert, fec_insert, usr_update, fec_update, usr_delete, fec_delete.
IDs manuales La mayoría usa BIGINT sin SERIAL (app genera el ID). Excepciones: tab_Opiniones y tab_Rate_Limits usan SERIAL.
ON CONFLICT Los seeds usan ON CONFLICT DO NOTHING para ser idempotentes.

Leyenda de Restricciones

Etiqueta Significado
PK Primary Key — Clave primaria de la tabla
FK Foreign Key — Relación con otra tabla
UNIQUE Valor único (no repetible en la tabla)
CHECK Validación de datos (rango, formato, valores permitidos)
INDEX Índice para rendimiento de consultas
DEFAULT Valor por defecto asignado automáticamente
